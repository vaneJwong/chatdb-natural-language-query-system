# Project history

This repository is the cleaned presentation version of the Natural Language Database
Query System completed for DSCI 551 in Fall 2024.

The working folders also contained two separate experiments that are not part of this
repository:

- `Project1.1`: an earlier ChatDB prototype using several small SQL and MongoDB datasets.
- `demo01`: a separate JSON/MapReduce experiment with generated temporary files.

They were left out to keep the public repository focused and runnable. Generated exports,
IDE metadata, bytecode caches, old code, and the assignment handout were also excluded.
