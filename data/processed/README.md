# Processed datasets

This directory contains processed versions of the three product datasets in both CSV and JSON formats. These are retained project outputs and are not the source files consumed by the database initialization flow in main.py.

Files:

- air_conditioners.csv and air_conditioners.json
- all_appliances.csv and all_appliances.json
- all_car_and_motorbike_products.csv and all_car_and_motorbike_products.json
